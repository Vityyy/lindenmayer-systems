# Implementation overview

The project has one namespace, `algo3-tp2-sistemasl.core`, which implements the
complete processing pipeline:

1. Read an L-System definition from `resources/`.
2. Parse its angle, axiom, and production rules.
3. Rewrite the axiom for the requested number of iterations.
4. Interpret the resulting symbols as turtle-graphics commands.
5. Calculate the drawing bounds and write the line segments as SVG.

See the root README for setup, commands, supported symbols, and an example
generated by the application.
