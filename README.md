# Lindenmayer Systems in Clojure

A small command-line L-System interpreter written in Clojure. It reads a
formal grammar, applies its production rules, interprets the resulting symbols
as turtle-graphics commands, and writes the drawing as SVG.

![Koch snowflake generated by this project](doc/snowflake.svg)

The image above is generated from `resources/nieve.sl` with four rewriting
iterations.

## How it works

The program uses a compact, deterministic pipeline:

1. Parse an angle, an axiom, and production rules from a `.sl` resource.
2. Rewrite every symbol for the requested number of iterations.
3. Interpret the expanded expression as immutable turtle-state transitions.
4. Use a stack to save and restore state for branching structures.
5. Calculate the drawing bounds and serialize its line segments as SVG.

Supported drawing commands:

| Symbol | Action |
| --- | --- |
| `F`, `G` | Move forward and draw |
| `f`, `g` | Move forward without drawing |
| `+` | Turn right by the configured angle |
| `-` | Turn left by the configured angle |
| `\|` | Reverse direction by 180 degrees |
| `[` | Push the current turtle state |
| `]` | Restore the previous turtle state |

## Run it

Requirements:

- Java JDK 8 or newer
- [Leiningen](https://leiningen.org/)

Clone the repository and run an included definition:

```bash
git clone https://github.com/Vityyy/lindenmayer-systems.git
cd lindenmayer-systems
lein run koch1.sl 4 output.svg
```

The arguments are:

```text
lein run <resource-file> <iterations> <output-svg>
```

Input files are resolved from `resources/`. Use a new output path or remove an
existing output first: the original academic implementation writes in append
mode.

## Input format

Each definition contains the turning angle, the axiom, and one production rule
per remaining line:

```text
90
F
F F-F+F+F-F
```

The repository includes Koch, Sierpinski, Dragon, Levy, Peano, tree, grid, and
other example systems under `resources/`.

## Tests

```bash
lein test
```

The tests cover expression rewriting, rule and resource parsing, movement,
rotation, immutable stack behavior, branching, drawing bounds, and SVG output.

## Project structure

```text
project.clj                         Leiningen project definition
src/algo3_tp2_sistemasl/core.clj   L-System engine, interpreter, and CLI
test/algo3_tp2_sistemasl/          Unit tests
resources/                         Example L-System definitions
doc/snowflake.svg                  Generated output shown above
```

The runtime depends only on Clojure 1.11.1 and its standard library.
